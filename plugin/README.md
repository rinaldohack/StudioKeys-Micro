# StudioKEYS plugin

Companion VST3 for **StudioKEYS Micro**.

- `StudioKEYS/` — iPlug2 project (VST3 shell)
- `ableton/StudioKEYS/` — Ableton Live MIDI Remote Script (Live cable)
- `third_party/iPlug2/` — iPlug2 SDK + dependencies

See `StudioKEYS/README.md` for VST3 build steps, and `ableton/StudioKEYS/README.md` to install the remote script.
